# LCA — LawCheck AI Public Website

This repository contains the compiled public LawCheck AI website published by Lux Automaton.

Website: <https://luxautomaton-ux.github.io/LCA/>

The private application source is maintained separately. This public repository does not contain local environment files, user evidence, exported attorney packets, test recordings, screenshots, Supabase CLI state, or development credentials.

LawCheck provides evidence organization and general information, not legal representation or legal advice. Production encrypted evidence storage, authoritative legal retrieval, secure attorney delivery, and subscription activation remain separate release gates.
